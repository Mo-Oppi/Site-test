Remplissez le formulaire, vérifiez l’aperçu, puis suivez l’étape tout en bas. Rien n’est publié tant que vous n’avez pas validé sur GitHub.

Cliquez ici, puis collez votre texte copié depuis Word (Ctrl+V ou Cmd+V).

Intertitres : ## Titre · gras : **mot** · italique : *mot* · lien : [texte](https://…) · image : ![description](images/nom.jpg) · citation : > texte · liste : - élément · note : [^1] dans le texte, puis [^1]: texte de la note en fin de document.

Aperçu

    Créer le fichier de l’article

    Sur GitHub : dépôt → dossier articles → Add file → Create new file. Copiez le nom ci-dessous dans le champ du nom, collez le contenu dans la zone de texte, puis Commit changes. C’est tout : la liste des articles se met à jour toute seule.

    Le site se met à jour environ deux minutes après la validation. Vous préférez Word ? Déposez simplement votre fichier .docx dans le dossier articles : cet outil devient inutile.
